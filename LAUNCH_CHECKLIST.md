**Release Notes Template:**
```markdown
# Clawganizer v1.0.0 - Initial Release 🎉

Welcome to Clawganizer! Your development workspace just got organized.

## What's Included

### Features
- ✅ Create projects with structure
- ✅ List active and archived projects
- ✅ Auto-organize workspace
- ✅ Archive old projects
- ✅ Track workspace status
- ✅ Generate documentation

### Installation
```bash
cp -r . ~/.openclaw/skills/clawganizer
```

Or use git:
```bash
git clone https://github.com/kakarot0105/Clawganizer.git ~/.openclaw/skills/clawganizer
```

### Quick Start
```bash
/clawganizer "create project MyApp"
/clawganizer "list projects"
/clawganizer "status"
```
