# Contributing to Clawganizer

Thank you for your interest in contributing! 

## How to Contribute

### Report Bugs
- Use GitHub Issues with title: `[BUG] Brief description`
- Include: reproduction steps, expected vs actual behavior

### Suggest Features
- Use GitHub Issues with title: `[FEATURE] Brief description`
- Explain the use case and why it would be useful

### Submit Code
1. Fork the repository
2. `pip install -e ".[dev]"`
3. Create feature branch: `git checkout -b feature/my-feature`
4. Make changes with clear commit messages
5. Run `pytest`
6. Push to your fork and open a Pull Request

## Code Standards

- Clear, descriptive commit messages
- One feature per Pull Request
- Document your changes
- Keep `clawganizer run` dry-run by default
